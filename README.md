# Hidden Design shorts media

Public copies of Hidden Design short videos, used so [Buffer](https://buffer.com) can fetch the files when scheduling posts for [@hidden.designs](https://www.tiktok.com/@hidden.designs) and Instagram Reels.

These are not source files and this is not a product repository. Published binaries are on the [v1 release](https://github.com/bekats1/hidden-design-shorts/releases/tag/v1).
